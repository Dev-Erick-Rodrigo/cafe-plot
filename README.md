# Plot Café ☕

Landing page de uma cafeteria, feita com HTML e CSS.

🔗 **Ver online:** https://dev-erick-rodrigo.github.io/plot-cafe/

## O que tem na página

- **Home:** apresentação com foto de fundo e botão de chamada
- **Sobre Nós:** foto e texto sobre a cafeteria
- **Nosso Menu:** 6 cards com foto, nome e preço
- **Avaliações:** 3 cards de clientes com estrelas
- **Endereço:** mapa do Google incorporado
- **Rodapé:** links das redes sociais

## Tecnologias

- HTML5
- CSS3 (flexbox, variáveis de cor, media queries)
- Google Fonts (Roboto)
- Font Awesome (ícones)

## Como rodar

1. Baixe ou clone o repositório
2. Abra o arquivo `index.html` no navegador

## Estrutura

```
plot-cafe/
├── index.html
├── css/
│   └── style.css
└── img/
```

Projeto de estudo de HTML e CSS, inspirado em um projeto do canal DevClub, com as minhas próprias imagens, cores e ajustes.
